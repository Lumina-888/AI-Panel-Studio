# AI Panel Studio — 三级弹窗排版重设计规范

> 2026-06-26 | 版本 v1.0

## 1. 设计目标

优化三级弹窗（创建讨论、确认嘉宾、确认删除）的排版布局，采用精致留白风格：
- 大间距、清晰分区、每块信息有呼吸感
- 内容区用嵌套卡片分层
- 所有按钮统一使用 SlideButton 滑动渐变按钮
- 按钮区三等分均布间距

## 2. 统一弹窗框架

```ascii
┌─ 遮罩 bg-black/70 backdrop-blur-sm ──────────────────┐
│                                                       │
│   ┌─ 主面板 glass-panel rounded-2xl animate-fade-in-up  ──┐
│   │                                                        │
│   │  标题栏 px-6 pt-6 pb-4                                 │
│   │  ├ 标题 text-lg font-semibold text-text-primary        │
│   │  └ 关闭按钮 hover:bg-white/10 rounded-lg              │
│   │                                                        │
│   │  ┌─ 内容卡片 mx-6 mb-6 ────────────────────────────┐  │
│   │  │  bg-white/[0.03] rounded-xl p-6                  │  │
│   │  │  border border-white/[0.06]                      │  │
│   │  │  space-y-6                                       │  │
│   │  └──────────────────────────────────────────────────┘  │
│   │                                                        │
│   │  ── border-t border-white/[0.06] ──                   │
│   │                                                        │
│   │  按钮区 px-6 pb-6 pt-4 flex justify-evenly gap-3      │
│   │                                                        │
│   └────────────────────────────────────────────────────────┘
│                                                       │
└───────────────────────────────────────────────────────┘
```

### 2.1 样式参数变更

| 元素 | 旧值 | 新值 |
|------|------|------|
| 弹窗宽度 | `480px` | 520px（创建）/ 480px（删除） |
| 标题栏内边距 | `p-5` | `px-6 pt-6 pb-4` |
| 内容区内边距 | `p-5` | 内嵌卡片 `p-6`，卡片外边距 `mx-6 mb-6` |
| 区块间距 | `space-y-4/5` | `space-y-6` |
| 标签与控件间距 | `mb-2` | `mb-3` |
| 按钮区间距 | `flex gap-3` 左对齐 | `flex justify-evenly` 三等分 |
| 按钮区与内容分隔 | 无 | `border-t border-white/[0.06]` |
| 关闭按钮 hover | 无 | `hover:bg-white/10 rounded-lg` |

### 2.2 按钮区均布规则

```
┌─ 主面板 ──────────────────────────────────────────┐
│                                                    │
│  ← d1 → [取消/返回修改] ← d2 → [确认/生成] ← d3 → │
│                                                    │
│  d1 = d2 = d3                                      │
│  实现: flex justify-evenly px-6 pb-6 pt-4 gap-3    │
└────────────────────────────────────────────────────┘
```

- 按钮：`[取消 (default)]` `[生成嘉宾阵容 (primary)]`

### 4.1 嘉宾卡片设计

```
┌──────────────────────────────────────────┐
│ ┃  ┌────┐                                │
│ ┃  │ 头 │  姓名    角色标签              │
│ ┃  │ 像 │  头衔 / 领域                   │
│ ┃  └────┘  立场描述                      │
│ ┃  3px 色条                               │
└──────────────────────────────────────────┘
```

- 左侧 3px 色条：`style={{ backgroundColor: p.color }}`（专家专属颜色）
- 头像 44px 圆形：`w-11 h-11 rounded-full`，背景色 `p.color + '22'`，文字 `p.color`
- 信息三行：姓名+角色标签 / 头衔 / 立场
- 卡片底：`bg-white/[0.02] rounded-xl border border-white/[0.04]`
- Hover：`-translate-y-0.5` + 亮度微增，`transition-all duration-200`
- 角色标签：主持人 `bg-accent-cyan/15 text-accent-cyan`，专家 `bg-white/[0.06] text-text-dim`
- 话题名在引导文案中用 `text-accent-cyan font-medium` 高亮
