# PRD — AI Panel Studio

## 产品定位

**AI Panel Studio** 是一款 AI 圆桌讨论本地 Web 应用。用户输入任意讨论问题并指定专家人数，系统调用大模型动态生成主持人+专家角色，随后 AI 驱动实时圆桌讨论，最终呈现一场沉浸式的 AI 演播厅实况。

**一句话：** 让任何人能瞬间召唤一支"虚拟智囊团"，围绕任意议题展开深度碰撞。

## 目标用户

| 群体 | 特征 | 诉求 |
|---|---|---|
| 知识工作者/研究者 | 需快速多角度审视议题 | 几分钟内获得深度分析与争辩 |
| 产品/决策人员 | 方案评审前预演各方立场 | 圈出观点盲点、检验假设 |
| 教育/内容创作者 | 结构化呈现复杂议题 | 获得可收录的"虚拟专家访谈"素材 |

## 用户痛点

1. **观点单一**：单一 AI 对话缺乏对抗性思考
2. **异见缺失**：多次独立询问不同角色，观点之间无法真正碰撞
3. **过程不可见**：AI 输出通常只有结论，缺少观点演化的实时感知
4. **议程管理混乱**：多议题并行探索时上下隔离困难

## 核心功能

### 1. 讨论列表
- 展示所有讨论（含 status、话题、参与人数、消息数）
- 支持创建新讨论、加入已有讨论
- 按状态分类：进行中 / 已结束

### 2. 创建讨论
- 用户输入话题 + 专家人数（默认 4 人）
- 系统调用 LLM 生成主持人 + 专家群像（姓名、职业、Title、立场、专属颜色）
- 用户确认/调整名单后进入讨论模式

### 3. 圆桌讨论
- **主持人**：开场 → 追问 → 串场 → 总结
- **专家**：自主发言（非轮询），每人 1-2 句，允许抢答/补充/反驳
- **专家状态小窗**：实时显示 standby / preparing / speaking + 当前关注点
- **实时共识与分歧**：讨论中持续提炼，实时更新
- **实时 Transcript**：发言流，颜色块区分发言人
- **主持人总结**：自然语言总结，不暴露 JSON

## 技术要求

| 维度 | 要求 |
|---|---|
| 架构 | 前后端分离，API Key 仅存后端环境变量 |
| 实时通信 | SSE 或 WebSocket |
| 数据库 | SQLite |
| 多讨论 | 状态、事件流、Transcript 完全隔离 |
| UI | 中文、响应式、各区域独立滚动 |
| 模型 | DeepSeek V4 Pro |

## 开发范式

```
SDD（契约驱动）→ DDD（设计驱动）→ TDD（测试驱动）→ E2E
```

- **SDD**：数据模型 + API 契约先行
- **DDD**：演播厅视觉风格驱动组件设计
- **TDD**：核心逻辑测试先行（嘉宾生成、发言调度、共识提炼）
- **E2E**：Playwright 系统级端到端测试

## 非功能需求

- 本地运行，无需联网（除 LLM API 调用）
- 数据库文件不提交到 Git
- Git 提交历史呈现清晰层级
- 完整的开发文档与 Prompt 记录
